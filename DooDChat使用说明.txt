DooDChat 一键使用说明
=================

一、第一次使用前

1. 电脑需要安装 Node.js 20 或更高版本。
   官方下载地址：https://nodejs.org/
2. 第一次启动如果缺少依赖，启动器会自动安装；此时需要网络连接。
3. Windows 首次弹出防火墙提示时，只勾选并允许“专用网络”，不要开放“公用网络”。

二、启动

1. 双击项目根目录中的“启动DooDChat.cmd”。
2. 等待黑色窗口显示“DooDChat 已启动”。
3. 默认浏览器会自动打开本机聊天室。
4. 黑色窗口还会列出局域网地址。同一 Wi-Fi 或同一局域网中的朋友，可在浏览器中打开对应地址。
5. 如果列出了多个地址，优先尝试与电脑当前 Wi-Fi/网线同一网段的地址；无效地址通常来自虚拟网卡，可以忽略。

三、使用期间

1. 黑色窗口必须保持开启；最小化即可，不要关闭。
2. 朋友只需要打开地址并输入昵称，不需要注册账号。
3. 如果配置了房间密码，启动窗口只提示“已启用”，不会直接显示密码。
4. 手机或异地设备的麦克风通常要求 HTTPS。这个启动器只负责本机和私人局域网启动，不会自动开放公网。

四、新界面和快捷功能

1. 输入框支持多行：回车发送，Shift+Enter 换行；最多 500 个字符。
2. 输入“@”会显示在线成员，可用上下方向键选择，按 Tab 或回车确认。
3. 向上查看旧消息时，右下角会出现“回到底部”按钮。
4. 点击顶部天气图标，可以让房间所有人一起切换雨夜、落雪、星空或樱花。
5. 音乐播放时封面会变成黑胶唱片，顶部歌词按当前一句逐字扫光。
   在音乐面板粘贴网易云歌单链接即可分享；普通歌单链接和 163cn.tv 分享短链都支持。
6. 可以发送快捷指令：/shrug（耸肩）、/tableflip（掀桌）、/unflip（扶桌）；
   还有 /roll（掷骰子，可加上限如 /roll 6）、/coin（抛硬币）、/pick 选项1 选项2（随机抉择）；输入 /help 查看全部指令。
7. 按 Ctrl+/ 可以查看快捷键说明，按 Esc 关闭弹窗或抽屉。
8. 每条文字或图片消息旁都有一个“···”消息操作入口，点开后可选择“回复”或表情；回复时输入区会显示引用内容，点右侧×可取消，点击回复引用可跳回仍在页面中的原消息。
9. 表情回应支持 👍、❤️、😂、😮、😢、👀；再次点击自己已选的表情可以撤销，鼠标悬停可查看参与者。
10. 图片仍可点击查看大图；通知权限只有主动点击“开启 @ 提醒”后才会申请。
11. 如果系统开启“减弱动态效果”，天气、闪电和黑胶旋转会自动减少或关闭。
12. 聊天区减少了大面积紫色发光，长消息、引用和回应文字更清晰；雨夜氛围仍会保留，但不会盖住消息。

五、安全结束

1. 所有人使用结束后，回到黑色窗口。
2. 按一次回车。
3. 看到“DooDChat 已安全关闭”后，本轮聊天、图片、音频缓存、歌单及其他会话状态已经清理。
4. 不需要查找缓存文件夹，也不需要点击清理按钮。

如果误关窗口、电脑断电或程序崩溃，无法当场执行清理；下次启动 DooDChat 时会自动清除带 DooDChat 归属标记的运行期内容。旧版本遗留的无标记目录不会自动删除；遇到启动提示时先自行确认并备份，不要直接删除未知文件。

六、房间自动结束规则

- 第一名认证用户进入后，本轮房间开始。
- 最后一名认证用户离开后，默认等待 10 分钟。
- 10 分钟内有人回来，本轮房间继续。
- 10 分钟内无人回来，程序自动结束并清空本轮房间。
- 服务器正常关闭时不等待 10 分钟，立即清理。

七、常见问题

1. 提示“没有找到 Node.js”
   安装 Node.js 20 或更高版本，然后重新双击启动文件。

2. 提示“端口已被占用”
   DooDChat 可能已经启动。检查是否还有另一个标题为 DooDChat 的黑色窗口，不要重复启动。

3. 浏览器没有自动打开
   手动复制黑色窗口中的“本机访问”地址到浏览器。

4. 朋友无法打开局域网地址
   确认双方在同一 Wi-Fi/局域网，并确认 Windows 防火墙已允许 Node.js 使用专用网络。

5. 误关窗口后是否需要手工清理
   带 DooDChat 归属标记的运行期内容会在下次启动时清理；无标记的旧文件不会自动删除。

八、朋友不在同一网络时（公网穿透）

启动器本身只开放本机和局域网。朋友在异地时，需要用"内网穿透"工具把你电脑上的 3000 端口
临时映射成一个公网 https 地址。以下几种都可以，任选一种；步骤都是：先带密码启动 DooDChat → 再开穿透 → 把地址和密码分开发给朋友。

【第 0 步：一定要带房间密码启动】
   打开 CMD，进入 DooDChat 所在目录后执行（密码至少 12 位，别用生日、手机号）：
      set "ROOM_PASSWORD=你的房间密码"
      启动DooDChat.cmd
   不要在没有密码的情况下开公网。

【方式 A：cpolar（国内访问较稳）】
   1. 到 cpolar 官网下载 Windows 安装包并安装，注册账号后在网页后台复制你的 authtoken。
   2. 第一次使用，在 CMD 执行一次：cpolar authtoken 你的authtoken
   3. 每次使用执行：cpolar http 3000
   4. 窗口里 "Forwarding" 一行会出现 https://xxxx.cpolar.top（或类似）地址；
      也可以打开 http://localhost:9200 在本地后台查看。把这个地址发给朋友。
   5. 免费版每次重启地址会变、带宽有限；固定域名需要付费套餐。
   6. 用完在 cpolar 窗口按 Ctrl+C 关闭隧道。

【方式 B：Cloudflare 快速隧道（免注册）】
   1. 安装一次：winget install --id Cloudflare.cloudflared
   2. 每次使用执行：cloudflared tunnel --url http://localhost:3000
   3. 窗口里会出现 https://xxxx.trycloudflare.com 地址，发给朋友。
   4. 地址每次都变，国内部分网络访问 Cloudflare 可能较慢。
   5. 用完按 Ctrl+C 关闭。

【方式 C：ngrok】
   1. 官网下载并注册，执行一次：ngrok config add-authtoken 你的token
   2. 每次使用执行：ngrok http 3000
   3. 窗口里 "Forwarding" 行的 https 地址发给朋友；第一次打开时朋友需要点一下页面上的确认按钮。

【方式 D：Tailscale（不开公网，最安全，但双方都要装）】
   1. 你和朋友都安装 Tailscale 并登录同一个账号（或互相加为好友共享设备）。
   2. 朋友直接打开 http://你的Tailscale地址:3000（在 Tailscale 客户端里能看到 100.x.x.x 地址）。
   3. 这种方式没有公网入口，但仍建议设置房间密码；浏览器在 http 地址下不能开麦克风，
      需要语音的话执行 tailscale serve 3000 之后用它给出的 https 地址。

【注意事项】
   - 所有穿透工具都会在本机多开一个窗口，使用期间不要关闭；用完先关穿透，再回 DooDChat 窗口按回车关闭。
   - 穿透地址等于一把钥匙，只发给要一起聊天的人，不要发到群里或公开平台。
   - 手机端麦克风必须是 https 地址（方式 A/B/C 都自带 https）。异地语音受双方网络影响，偶尔连不上属正常。
   - 不要在路由器上直接把 3000 端口映射到公网；这样没有 HTTPS，容易暴露房间通信。

------------------------------------------------
【2026-09-23 新功能】

1. 撤回消息：在自己消息的右上角「…」工具里点「↺ 撤回」；
   发送后 2 分钟内可撤，撤回后原位置显示「你撤回了一条消息」。
   发出去的图片撤回后服务器会一起删掉临时文件，链接立即失效。
2. 复制消息：工具栏新增「⧉ 复制」，一键复制这条消息的全部文字。
3. 拖图发送更方便：把图片拖到聊天窗口任意位置（不用对准输入框），
   出现「松开即发送图片」提示后松手即可；一次最多 4 张。
4. 手机快捷手势：用右手边往左滑——上半屏滑开成员列表、下半屏滑开音乐面板；
   面板打开时往右滑就关闭。
5. 顶栏的在线人数、连接状态、天气和昵称做成胶囊样式；点引用跳回原消息时
   会有脉冲高亮提示；系统开启「减弱动态效果」后动画全部自动关闭。

------------------------------------------------
【2026-09-24 改进】

1. 断线重连更稳：网络抖动后自动重连时，你之前发的消息仍然算你自己的，
   还能照常撤回；聊天记录不再闪一下重画，断线期间别人发的消息会自动补上。
   （默认断线 10 分钟内有效，超过则按新加入处理。）
2. 昵称不能只由看不见的字符组成，会提示重新输入。
3. 输入 /help 可以看到全部快捷指令。
